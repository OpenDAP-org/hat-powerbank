# Powerbank HAT requirements

Requirements for this project.

| ID | Requirement | Priority | Status |
|---|---|---|---|
| PWR-001 | This HAT is a complete project: hardware, case, firmware, software, DAP OS package and its own tooling. | must | Confirmed |
| PWR-002 | Its DAP OS software shall be a custom implementation built on popular open-source software for its domain, optimized for this HAT and the board. | must | Confirmed |
| PWR-003 | It shall mount through the HAT Case Standard. | must | Confirmed |
| PWR-004 | It may include on-board AI features. | should | Draft |
| PWR-005 | The HAT shall work as a powerbank. | must | Confirmed |
